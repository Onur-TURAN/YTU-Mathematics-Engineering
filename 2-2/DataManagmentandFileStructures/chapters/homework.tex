\section*{Project Objective}

Design and implement a complete database system for a Smart Healthcare Platform that supports:

\begin{itemize}
    \item Multi-user access (patients, doctors, admins)
    \item Complex data relationships (EER level)
    \item Query optimization and indexing
    \item Real-world constraints and normalization
\end{itemize}

This project directly satisfies course outcomes like:

\begin{itemize}
    \item ER/EER modeling
    \item Relational schema design
    \item Functional dependencies \& normalization
    \item SQL querying
    \item File structures \& indexing
\end{itemize}

\subsection*{Project Scenario}

You are developing a database system for a large hospital network that includes:

\begin{itemize}
    \item Multiple hospitals and departments
    \item Doctors with different specialties
    \item Patients with medical histories
    \item Appointments, prescriptions, and lab results
    \item Insurance and billing system
\end{itemize}

The system must support efficient querying, integrity, and scalability.
